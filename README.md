# cc-config

A small grab-bag of [Claude Code](https://docs.claude.com/claude-code) configurations, scripts, and tips I find useful day-to-day.

Use whatever's helpful, ignore the rest. Each subfolder has its own README with install instructions.

## Contents

- [`scripts/`](./scripts) — shell scripts you can wire into Claude Code (status lines, hooks, etc.)
  - [`context-bar.sh`](./scripts/context-bar.sh) — two-line status line showing model, context usage, cost, git state, and your last message.
